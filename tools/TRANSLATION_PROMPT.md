# Script/Skit/MapData 씬 번역 프롬프트

`2_translated/{script,skit,map}_wip/`의 씬 파일 하나를 번역할 때 쓰는 절차입니다.
AI 번역 도우미(Claude 등)에게 씬 단위로 요청할 때 아래 내용을 그대로 붙여넣고
파일 경로만 바꿔서 쓰면 됩니다. **전체 파일을 한 번에 요청하지 말고, 반드시
씬(파일) 하나 단위로 요청하세요.**

---

## 프롬프트

```
다음 CSV 파일 하나를 한국어로 번역해줘: <파일 경로, 예: 2_translated/script_wip/Dn_00_05_100.dat.csv>

작업 방식:
1. 파일을 읽고, 비어 있는 Korean 컬럼을 채워서 그대로 덮어써줘.
2. 번역하기 전에 Tales-of-Innocence-R/GLOSSARY_KO.md를 참고해서:
   - 캐릭터/지명 고유명사는 용어집에 있는 한글 표기를 그대로 써줘
     (예: ルカ→루카, イリア→이리아, レグヌム→레그눔).
   - 화자(Speaker 컬럼)가 있으면 용어집의 "캐릭터 말투 패턴" 표를 참고해서
     그 캐릭터의 말투(반말/존댓말, 종결어미, 사투리 여부 등)를 유지해줘.
     예: 에르마나=경상도 사투리, 큐큐=어순이 어색한 서툰 말투, 스파다=거친 말투 등.
3. {blue}, {white}, {variable}, {fixed}, {remap_l1}, {icon:0x0006} 같은
   중괄호 제어 태그는 원문에 있는 것과 정확히 같은 개수·형태로 번역문에도
   그대로 남겨줘 (내용만 번역하고 태그는 건드리지 마).
4. 원문의 줄바꿈(\n) 구조는 최대한 유지해줘. 다만 어색하면 한국어 어순에
   맞게 줄바꿈 위치를 조정해도 괜찮아.
5. 번역문에 콤마(,)가 들어가면 CSV 필드를 반드시 큰따옴표로 감싸줘
   (예: "야, 무슨 소리야" — 감싸지 않으면 컬럼이 깨짐). 이건 이 작업에서
   가장 자주 나는 실수니까 특히 주의해줘.
6. 원문이 "なし"(없음을 뜻하는 플레이스홀더)면 "없음"으로 옮겨줘.
7. 저장한 뒤 아래 명령으로 검증해줘:
   python tools/translate_helper.py check <script|skit|map>
   (Tales-of-Innocence-R/ 디렉터리에서 실행. 태그 누락이나 용어 불일치가
   있으면 출력에 나오니 확인 후 고쳐줘.)
8. 마지막으로 python tools/translate_helper.py progress로 전체 진행률을
   확인해줘.

번역이 끝나면 무엇을 번역했는지(등장 캐릭터, 장면 요지) 한두 줄로만
요약해줘 — 대사 원문이나 번역문 전체를 다시 나열하지는 말고.
```

## 참고: 캐릭터 말투 요약 (자세한 내용은 GLOSSARY_KO.md 참고)

| 캐릭터 | 말투 |
|---|---|
| 루카 | 수줍은 반말, "僕"=나 |
| 이리아 | 털털한 반말, "わよ/わ" |
| 스파다 | 거친 말투, "だぜ" |
| 앙쥬 | 다정한 누나 말투 |
| 리카르도 | 간결하고 딱딱함 |
| 에르마나 | 경상도 사투리 |
| 콘웨이 | 쿨한 반말, "ボク"=나 |
| 큐큐 | 서툰 말투, 3인칭 자기 지칭 |
| 코다(금/은) | 문장 끝마다 "그나저나" 붙임 |

## 참고: 파일별 컬럼 구조

- `script_wip/*.csv`: `File,#,Speaker,Japanese,Korean`
- `skit_wip/*.csv`: `File,Field,Index,Speakers,Japanese,Korean`
- `map_wip/*.csv`: `Path,Section,#,Speaker,Japanese,Korean`

마지막 `Korean` 컬럼만 채우면 됩니다. 다른 컬럼은 건드리지 마세요.
